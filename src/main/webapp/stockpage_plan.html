추가 구현이 필요한 핵심 기능들

창고간 재고 이동

기능: A창고 → B창고로 재고 이전

사용 시나리오:

  • 자재창고 → 생산라인
  • 완제품창고 → 출하대기실
  • 창고 통합/분리 작업
StockTransferDTO, 이동 이력 로그 필요
재고 조정 (Stock Adjustment)

기능: 실제 재고와 시스템 재고 차이 보정

사용 시나리오:

  • 재고 실사 후 차이 발생
  • 분실/파손으로 인한 감소
  • 시스템 오류 보정
StockAdjustmentDTO, 조정 사유 필수
재고 알림 관리

기능: 안전재고/만료일 등 알림 설정

알림 종류:

  • 안전재고 미달 (빨간색 배지)
  • 재고 부족 (노란색 배지)
  • LOT 만료 임박
  • 장기 재고 (Dead Stock)
알림 설정 모달, 배치 작업 필요
LOT/배치 관리

기능: LOT별 상세 추적 및 관리

관리 항목:

  • LOT별 수량 분할 조회
  • 제조일/유효기간 관리
  • 선입선출(FIFO) 기준 출고
  • 불량 LOT 격리
LOT 상세 모달, 만료일 계산 로직
구현 우선순위 추천
